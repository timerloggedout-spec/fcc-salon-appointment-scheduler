# Build a Salon Appointment Scheduler

FreeCodeCamp Relational Databases v9 certification project (unit 040).

- `salon.sql` — recreates the `salon` database (customers, services, appointments) with five seed services.
- `salon.sh` — interactive Bash scheduler: lists services, books appointments for new and returning customers.

Built as a fleet run in timerloggedout-spec/termux-monorepo (`cert-project.yml` run 41379885682, fileset mode):
structure stories verified in-run and the course's scripted booking flows replayed green.
